## ⚡ Quick Command Reference

### Cleanup (Delete Old Files)
```powershell
Remove-Item -Recurse -Force "wp-admin"
Remove-Item -Recurse -Force "diag"
Remove-Item -Recurse -Force "modern-blog-app/backend"
```

### Setup Frontend
```bash
cd modern-blog-app/frontend
npm install
npm run dev
# Open http://localhost:3000
```

### Deploy
```bash
git add .
git commit -m "Supabase setup"
git push origin main
# Vercel auto-deploys!
```
